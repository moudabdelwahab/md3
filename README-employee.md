# نسخة HTML + CSS + JavaScript

هذه نسخة مستقلة من نظام **مدعوم — عمليات الموظفين** دون React أو TypeScript أو أدوات بناء. افتح `employee.html` في متصفح حديث لتشغيل الواجهة.

| الملف | المسؤولية |
|---|---|
| `employee.html` | البنية العربية RTL، التنقل، الحوار، ونقاط تحميل الموارد |
| `css/employee.css` | نظام الألوان، التخطيط المتجاوب، الوضع الداكن، والمكونات |
| `js/employee.js` | الجلسة المحلية، الحضور، الاستراحات، النشاط، التقارير، ورسوم Canvas |

لا يوجد Backend أو قاعدة بيانات. تُحفظ حالة الاستخدام مؤقتًا داخل `sessionStorage` في المتصفح نفسه، ولا يُرصد أي تفاعل خارج التطبيق.
