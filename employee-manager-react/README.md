# التحقق من لوحة المدير المحلية

تم التحقق من أن المدير يرى الجلسة المحلية الفعلية في جدول الحضور، وأن عدادات الوردية والنشاط والاستراحة تتبدل مع حالة الجلسة. ظهرت إشارة الاستراحة في لوحة التنبيهات عند بدء استراحة محلية.

تستخدم اللوحة قناة المتصفح المحلية بين علامات التبويب فقط. لا توجد أي اتصالات خادمية أو قاعدة بيانات أو مصادقة خارج الجلسة المحلية. بعد التحقق، مُسحت بيانات جلسة الاختبار من معاينة المتصفح.

بدأ اختبار إضافي لأدوات الجدول الجديدة باستخدام جلسة مدير محلية منفصلة، للتحقق من الفلترة والترتيب والتصدير داخل المتصفح فقط.

تم إدخال بيانات جلسة اختبار محلية واختيار دور المدير لفتح أدوات الجدول، من دون استخدام أي بيانات اعتماد حقيقية أو إضافة بيانات موظفين افتراضية.

ظهرت أدوات فلتر الحالة وترتيب الجدول وزر تصدير CSV على السجل المحلي الفعلي للمدير، مع بقاء القيم المعروضة مشتقة من الجلسة فقط.

أُجري اختبار فلتر الحالة النشطة؛ ظهرت حالة فارغة سليمة عند غياب نتائج مطابقة، ثم عادت جلسة المدير الحالية بعد إعادة الفلتر إلى كل الحالات.

تم تغيير الترتيب إلى الحالة ثم تنفيذ تصدير CSV للسجل المحلي المفلتر. يعتمد الملف على الصفوف المعروضة حاليًا ويُنشأ داخل المتصفح.
